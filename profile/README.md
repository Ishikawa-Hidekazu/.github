# Ishikawa Hidekazu

Small, reviewable tools for safe AI operations.

Local diagnostics, public-source intake, and evidence-ready workflows with explicit safety boundaries.

## Projects

### [QuotaTempo](https://github.com/Ishikawa-Hidekazu/quota-tempo)

A native macOS menu-bar app for planning weekly Codex and Claude capacity.

[Download for macOS](https://github.com/Ishikawa-Hidekazu/quota-tempo/releases/latest) · [Setup guide](https://github.com/Ishikawa-Hidekazu/quota-tempo/blob/main/docs/user-guide.md) · [日本語ガイド](https://github.com/Ishikawa-Hidekazu/quota-tempo/blob/main/docs/user-guide.ja.md) · [Feedback and questions](https://github.com/Ishikawa-Hidekazu/quota-tempo/discussions/2) · [Read the story](https://taupe.site/entry/quotatempo-weekly-ai-capacity-planner/)

Requires macOS 14 or newer on Apple silicon.

### [codex-healthkit](https://github.com/Ishikawa-Hidekazu/codex-healthkit)

Metadata-only local health reports for daily Codex operators.

[Run a pinned version](https://github.com/Ishikawa-Hidekazu/codex-healthkit#30-second-quick-start) · [Preview a report](https://github.com/Ishikawa-Hidekazu/codex-healthkit/blob/main/examples/report.redacted.md) · [Report an issue](https://github.com/Ishikawa-Hidekazu/codex-healthkit/issues/new/choose)

The preview is a fixed example, not a check of your machine. The default check reads local metadata and does not upload a report.

### [public-source-extractor](https://github.com/Ishikawa-Hidekazu/public-source-extractor)

Public-URL intake with reviewable Markdown or stable JSON output.

[Preview output](https://github.com/Ishikawa-Hidekazu/public-source-extractor#preview-output-before-installing) · [Install](https://github.com/Ishikawa-Hidekazu/public-source-extractor#install) · [Run on a public URL](https://github.com/Ishikawa-Hidekazu/public-source-extractor#quick-start) · [Report an issue](https://github.com/Ishikawa-Hidekazu/public-source-extractor/issues/new/choose)

The preview uses fixed documentation samples. Extracting your URL sends it to Firecrawl Cloud; the experimental provider may be unavailable.

## Principles

- Local-first by default
- Metadata before contents
- Readable output
- Explicit safety boundaries
- Small tools over large platforms
