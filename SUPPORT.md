# Support

## Project Support

Use the affected repository's issue tracker for reproducible bugs, documentation gaps, and focused feature requests. Check its README and existing issues before opening a new report.

Please include the project version, operating system, relevant runtime version, reproduction steps, expected behavior, actual behavior, and redacted output when useful.

Do not post credentials, tokens, cookies, signed URLs, private content, account identifiers, raw transcripts, or customer data.

## Security Reports

For suspected vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.

Third-party service availability, billing, accounts, and upstream product behavior are outside the support scope of these repositories unless the repository documentation explicitly says otherwise.
